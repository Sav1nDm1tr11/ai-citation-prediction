# AI Citation Prediction for P&G Products

Проект оценивает вероятность цитирования веб-страницы в генеративном ответе по признакам её контента, структуры, URL и поискового запроса. Основная модель — логистическая регрессия с регуляризацией; задача анализа — проверить качество прогноза и устойчивость интерпретации коэффициентов.

## Данные

Исходный файл `data/PG_GEO_Dataset.xlsx` содержит 218 строк, 55 модельных признаков, шесть столбцов метаданных и бинарную цель `cited_in_generative_answer`. Перед анализом исключаются 23 внутренние ссылки поисковой выдачи: они не являются страницами источников. Остаётся 195 страниц, из которых 110 процитированы и 85 нет. Расшифровка признаков — в [FEATURES.md](FEATURES.md).

## Метод

1. Стратифицированное разделение: 156 страниц для обучения, 39 для теста.
2. На обучающей части удаляются константные и сильно коррелирующие признаки; в текущем запуске осталось 49. Заполнение пропусков и стандартизация для модели выполняются внутри `Pipeline`.
3. Бейзлайн сравнивается с RFECV и подбором регуляризации через Optuna. Optuna проверяет `C` и `l1_ratio` в 50 попытках, минимизируя Log Loss.
4. Качество оценивается на обычных и групповых фолдах. В групповой проверке один запрос не попадает одновременно в обучение и проверку.
5. Устойчивость коэффициентов оценивается бутстрапом по запросам и сравнением моделей, обученных на разных групповых фолдах.
6. Финальная логистическая регрессия проверяется на отложенной тестовой части. Результаты, таблицы и интерактивные графики записываются в ClearML.

RFECV на текущих данных не улучшил качество: внешний ROC-AUC снизился с 0,716 до 0,682, а Log Loss вырос с 0,711 до 0,741. Поэтому финальная модель использует признаки после начальной фильтрации, без RFECV.

## Текущие результаты

| Проверка | Модель | ROC-AUC | Log Loss |
| --- | --- | ---: | ---: |
| Внешняя CV на обучении | Бейзлайн | 0,716 | 0,711 |
| Внешняя CV на обучении | Optuna | 0,688 | 0,624 |
| Групповая CV по запросам | Бейзлайн | 0,755 | 0,673 |
| Групповая CV по запросам | Optuna | 0,760 | 0,588 |
| Отложенный тест, 39 страниц | Финальная логистическая регрессия | 0,604 | 0,691 |

Регуляризация улучшила Log Loss в среднем, но улучшение ROC-AUC неустойчиво. На тесте качество ниже, чем на групповых фолдах; при 39 тестовых страницах оценка чувствительна к составу выборки. Тест уже использовался для анализа ошибок, поэтому дальнейший выбор модели по его результату был бы оптимистичным.

На обучающих прогнозах CV самый слабый тип запроса — **рекомендательный**: ROC-AUC 0,512 и Log Loss 0,721 на 51 странице. На тесте для него ROC-AUC 0,444 и Log Loss 0,813 на 15 страницах. По товарным категориям самый высокий тестовый Log Loss у **Oral Care**: 0,796 на 18 страницах. Эти срезы диагностические, особенно малые группы теста.

Есть ограничение самих признаков: у 16 одинаковых наборов значений встречаются обе метки цитирования. Это 66 из 195 страниц; на наблюдаемом датасете любая детерминированная модель, использующая только эти признаки, ошибётся как минимум на 27 строках. Возможные причины — слишком грубые признаки или неучтённый контекст цитирования.

Бутстрап по 26 запросам дал устойчивое направление связи у 17 из 49 признаков; те же 17 сохранили знак на трёх групповых фолдах. Это проверка устойчивости, а не доказательство статистической значимости или причинного влияния признаков.

## Визуализации

[Ноутбук](notebooks/model_training.ipynb) строит только графики логистической регрессии: коэффициенты, ROC, Precision–Recall, матрицу ошибок, калибровку, Log Loss по сегментам и F1 по порогу на обучающих прогнозах CV. При запуске они сохраняются как интерактивные HTML-файлы в `notebooks/plots/` и отправляются в ClearML. История поиска Optuna и кривые обучения строятся в отдельных ячейках ноутбука.

Таблицы по категориям и типам запросов оценивают **прогнозы одной модели** внутри каждого сегмента. Модель не обучается заново на маленьких подгруппах. Таблица самых уверенных ошибок на тесте также сохраняется в ClearML.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/model_training.ipynb
```

Для отправки результатов настройте ClearML локально. Ключи доступа не следует добавлять в ноутбук или репозиторий.
