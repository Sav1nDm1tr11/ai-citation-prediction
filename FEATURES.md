# Справочник признаков датасета

В `data/PG_GEO_Dataset.xlsx` содержится 55 числовых признаков страницы и запроса. Они используются для предсказания бинарной целевой переменной `cited_in_generative_answer`: `1` — страница процитирована в генеративном ответе, `0` — не процитирована. Ещё шесть столбцов (`query`, `query_type`, `product_category`, `source_url`, `domain`, `source_type`) служат метаданными и не входят в приведённый ниже список модельных признаков.

Обозначение `0/1` означает отсутствие или наличие свойства. В группах с пометкой *one-hot* отдельный столбец соответствует одной категории. Описания и примеры ниже основаны на предоставленной расшифровке датасета.

## Бренд P&G

| Признак | Значения | Описание и пример |
| --- | --- | --- |
| `brand_mentioned` | 0/1 | Упоминается ли бренд P&G, например Oral-B, Blend-a-Med или Pampers. `1` — на странице есть «Oral-B»; `0` — упоминаний нет. |
| `brand_mention_count` | 0–20 | Число упоминаний бренда P&G в тексте. Например, `15` — официальный сайт Oral-B, `2` — бренд мелькает в рейтинге. |
| `brand_in_title` | 0/1 | Есть ли бренд P&G в заголовке страницы (title/H1). `1` — «Зубная щётка Oral-B Vitality — обзор»; `0` — «Лучшие зубные щётки 2025». |
| `num_competitors_mentioned` | 0–10 | Число упомянутых конкурентных брендов, например Philips, Colgate или Huggies. `5` — рейтинг с несколькими брендами; `1` — сравнение Oral-B и Philips. |
| `recommendation_sentiment` | −1, 0, +1 | Тональность рекомендации по отношению к бренду P&G: `+1` — положительная, `0` — нейтральная, `−1` — негативная или в пользу конкурента. |

## Контент о продукте

| Признак | Значения | Описание и пример |
| --- | --- | --- |
| `has_product_specs` | 0/1 | Есть ли конкретные характеристики продукта: состав, размеры, технологии или материалы. `1` — подробная карточка товара; `0` — общая статья. |
| `has_numeric_data` | 0/1 | Есть ли числовые данные: цены, рейтинги, проценты, результаты тестов. `1` — «890 ₽, рейтинг 4,7»; `0` — текст без цифр. |
| `numeric_data_count` | 0–15 | Количество отдельных числовых фактов о продукте. Например, `10` — подробный обзор, `3` — краткая карточка. |
| `has_comparison` | 0/1 | Есть ли прямое сравнение продукта P&G с конкурентами. `1` — таблица «Oral-B vs Philips Sonicare». |
| `has_recommendation` | 0/1 | Есть ли явная рекомендация: «лучший», «рекомендуем», «выбор экспертов». `0` — каталог без оценок. |
| `has_pros_cons` | 0/1 | Есть ли структурированный блок плюсов и минусов. `1` — отдельный список преимуществ и недостатков. |
| `has_user_reviews` | 0/1 | Есть ли пользовательские отзывы (UGC). `1` — секция отзывов на маркетплейсе; `0` — экспертная статья без отзывов. |
| `user_rating` | 0–5 | Средний пользовательский рейтинг товара на странице. `0` означает отсутствие рейтинга. |
| `review_count` | целое число | Количество пользовательских отзывов на странице. `0` означает отсутствие отзывов; `150` — товар с большим числом отзывов. |

## Структура страницы

| Признак | Значения | Описание и пример |
| --- | --- | --- |
| `has_structured_headings` | 0/1 | Есть ли иерархия заголовков H1 → H2 → H3. `1` — статья с разделами «Как выбрать», «Рейтинг», «Итоги». |
| `has_table_or_list` | 0/1 | Есть ли таблицы сравнения или структурированные списки. `1` — таблица характеристик либо нумерованный топ-10. |
| `has_faq` | 0/1 | Есть ли блок «Вопросы и ответы» (FAQ). |
| `content_length_words` | целое число | Примерная длина текста в словах. `3000` — длинная экспертная статья; `300` — карточка товара. |
| `product_focus_ratio` | 0–1 | Доля текста, посвящённая искомому продукту или категории. `1,0` — вся страница о продукте; `0,3` — упоминание в общем обзоре. |
| `readability_score` | 1–5 | Субъективная оценка читаемости: `5` — текст лёгкий и структурированный; `1` — сложный и перегруженный. |

## Релевантность запросу

| Признак | Значения | Описание и пример |
| --- | --- | --- |
| `query_answered_directly` | 0/1 | Отвечает ли страница непосредственно на поисковый запрос. `1` — статья «Как выбрать зубную пасту» для соответствующего запроса; `0` — общий каталог. |
| `covers_intent_fully` | 0/1 | Насколько полно страница покрывает намерение пользователя. `1` — развёрнутый гайд с критериями и выводом; `0` — каталог с фильтрами. |
| `information_gain` | 1–5 | Оценка уникальной информационной ценности источника. `5` — собственные тесты или данные; `1` — повтор сведений с других сайтов. |

## URL-сигналы

Эти признаки определяются по адресу страницы. Они описывают текст URL, а не подтверждают содержание или дату публикации.

| Признак | Значения | Описание и пример |
| --- | --- | --- |
| `url_has_review` | 0/1 | Содержит ли URL слова об отзывах (`review`, `otzyv`). `1` — путь `/review/`. |
| `url_has_rating` | 0/1 | Содержит ли URL слова о рейтинге (`rating`, `reyting`, `top`, `luchsh`). `1` — путь `/top-10-luchshikh-zubnykh-past/`. |
| `url_has_comparison` | 0/1 | Содержит ли URL слова о сравнении или выборе (`sravneni`, `vs`, `vybrat`). `1` — путь `/kak-vybrat-zubnuyu-pastu/`. |
| `url_has_article` | 0/1 | Похож ли URL на адрес статьи или блога (`article`, `stati`, `blog`, `journal`, `wiki`). |
| `url_has_catalog` | 0/1 | Похож ли URL на адрес каталога (`catalog`, `category`). |
| `url_has_brand_pg` | 0/1 | Упоминается ли бренд P&G в URL, например `oral-b` или `pampers`. |
| `url_has_year` | 0/1 | Указан ли в URL 2025 или 2026 год. `1` — путь `/top-zubnykh-past-2025-goda/`. |
| `url_has_how_to` | 0/1 | Похож ли URL на адрес обучающего материала (`kak-vybrat`, `kak-pravilno`, `chto-takoe`). |
| `is_serp_link` | 0/1 | Является ли URL внутренней ссылкой поисковой выдачи Яндекса вида `ya.ru/search/_crpd/...`, а не адресом реального источника. |
